# 我的 SecondMe 个性化使用约定（Private copy only）

> 仅空白模板。请把填写后的文件保存到自己私人仓库的 `custom/`，不要提交到公开 Framework。

## 我希望 SecondMe 怎么和我交流？

- 我喜欢简洁 / 长篇 / 先结论后证据 / 自由叙事 / 表格 / 图谱：
- 我希望被指出可能的盲点或反例的方式：
- 对尚不确定的判断，我希望如何标注：
- 我什么时候希望被主动问问题，什么时候只想聊天：

## 对我的分析中什么尤其重要？

- 希望深挖的主题（随时调整）：
- 最不希望被强行贴上的标签：
- 个人常用的词汇、隐喻或表达习惯：
- 愿意纳入的材料范围：
- 不愿记录的话题与隐私边界：

## Output 报告的偏好

- 完整 / 阶段 / 专题 / 访客：
- 希望保留的细节程度：
- 需要的事实/反例/优缺点表格：
- 是否保存到 Private Git / 本地 / 不保存：
- 谁可以看到哪一份版本：

## 纠错优先

- 当我说模型理解错了，应如何记录纠正：
- 希望保留的旧版本与修订日志：
- 什么时候不应进一步推断：

**这不是人格测试，是用户自己的使用权与修改权。**
