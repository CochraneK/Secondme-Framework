# Evidence Card｜单个私人事实的可追溯记录（空白模板）

> 复制到**自己选定的私有** my/evidence/ 路径。只记录足以支持后续判断的最少材料；不要把完整第三方聊天、敏感证件、原始诊疗资料上传至公共仓库。本模板无真实人物资料。

| 字段 | 内容 |
| --- | --- |
| evidence_id | E-待填写（本人仓库内唯一） |
| source_kind | SELF_REPORTED / EVENT / OBSERVED / EXTERNAL / UNKNOWN |
| source_pointer | 本人可访问的原始来源；若无则注明由本人回忆 |
| speaker_id | P-SELF / 已确认的 P-ID / UNKNOWN |
| subject_id | 谈论对象的 P-ID / UNKNOWN；不一定是说话者 |
| quoted_speaker | 引用原话的发言者 / NONE / UNKNOWN |
| event_time | UNKNOWN |
| recorded_at | UNKNOWN |
| interpreted_at | UNKNOWN |
| privacy | PRIVATE / LOCAL_ONLY / DECLINED |
| consent_scope | 仅本人 / 指定范围；未知则不分享 |
| verification_status | SELF_ACCOUNT / DOCUMENTED / UNVERIFIED |
| linked_claim_ids | 未关联 |
