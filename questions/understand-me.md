# Understand Me · 用户 → AI 的自我认识问题库 v0.2

> **目标**：用户在已有一定自述/经历/他人明确反馈后，主动向 AI 寻找**有来源的镜像、矛盾、反证、纵向变化与帮助行动的选择**。  
> **使用方式**：可以直接复制任意一个 U 编号问题（U01–U48）；不必按顺序、不必回答所有题。AI 没有看到相关记录时，必须承认，并可建议用户自愿提供一个非敏感例子。  
> **框架**：[双向问题系统](../framework/two_way_question_system.md) · [AI 采访问题](discover-me.md)

## A. 六个核心镜像问题（建议优先尝试）

| ID | 用户可以直接问 AI 什么？ | 期待 AI 做什么 |
| --- | --- | --- |
| **U01 · 人物镜像** | **基于你确实能看到的材料，你觉得我是怎样的人？哪些是事实、哪些只是推测、哪些还不知道？** | 承认可见范围，先把事实与解释分开 |
| **U02 · 优势与代价** | **我最有证据支持的三个优势是什么？它们在什么情境下也可能成为负担？** | 不只夸奖，说明表现与适用范围 |
| **U03 · 行为盲区** | **我有哪些自己可能忽略的反复行为模式？请用具体例子，而不是形容词。** | 给来源、多个事件和竞争解释 |
| **U04 · 言行差距** | **我自认为重视的事情，与实际选择中体现的东西，有什么一致和不一致？** | 别直接作道德评判；考虑约束条件 |
| **U05 · 反证与自纠** | **如果要证明你目前对我的理解可能是错的，最有力的反例是什么？你会撤回哪条判断？** | 主动挑战原模型、允许降权和退役 |
| **U06 · 下一问** | **如果只能再问我一个问题，什么最有可能改变你对我的认识？为什么？** | 选择信息增益大的问题，不能单为新奇 |

## B. 十八个通用深化问题（U07–U24）

### 真实能力、动机与环境

| ID | 可直接发给 AI 的问题 | 验证边界 |
| --- | --- | --- |
| U07 | 我有哪些实际能力是被真实行为或作品支持的？哪些还只是兴趣、愿望或自述？ | 不把听课、收藏当熟练 |
| U08 | 在什么环境里我可能表现得更好？换个环境，哪些优势可能失效？ | 区分情境与稳定倾向 |
| U09 | 我有哪些做得不错却不喜欢做的事情？有哪些喜欢但暂时不擅长的事情？ | 区分喜欢、技能、意愿 |

### 情绪、关系与被看见

| ID | 可直接发给 AI 的问题 | 验证边界 |
| --- | --- | --- |
| U10 | 面对被误解、拒绝、失败或不公时，我的反应有什么差异？ | 避免所有矛盾都归因于一种性格 |
| U11 | 我在关系中怎样表达关心？对方实际表达过怎样的体验？ | 严格区分双方说法与 AI 猜测 |
| U12 | 他人眼中的我，与我对自己的理解有哪些有证据的差异？各自可能看不到什么？ | 无第三方原话时不编造他人看法 |

### 时间、价值与重要选择

| ID | 可直接发给 AI 的问题 | 验证边界 |
| --- | --- | --- |
| U13 | 与几年前相比，我发生过哪些有证据支持的变化？哪些可能只是短期状态？ | 按时间与情境分开 |
| U14 | 我在哪些决定中付出了真实代价？这些选择最清楚地体现了什么价值？ | 行为未必反映自由选择 |
| U15 | 我有哪些反复出现却没有完全解决的问题？它们可能指向什么更高层问题？ | 母问题是候选，不是神秘定论 |

### AI 偏差、竞争解释和推断审计

| ID | 可直接发给 AI 的问题 | 验证边界 |
| --- | --- | --- |
| U16 | 你有哪些关于我的判断可能只是因为我讲得生动，你就相信了？ | 识别叙事效应和样本选择 |
| U17 | 你是不是在安慰我、迎合我或夸大我的优点？请列出最值得怀疑的三条结论。 | 允许否定与修正，不能防御旧回答 |
| U18 | 对于你最确信的一项人格解释，还有哪些合理的竞争解释？怎样用新证据区分它们？ | 不虚构等概率或伪精确分数 |

| U20 | 你对我了解得很详细，但有没有哪一类普通生活几乎没有证据？ | 找真正的未知，不强求填写 |
| U21 | 我的哪些愿望是自己明确选择的，哪些可能只是社会期待或我对自己的要求？ | 区分现时本人确认与 AI 价值投射 |

### 行动、主体性与未来修订

| --- | --- | --- |
| U22 | 结合我的现实约束，哪些小尝试最能帮助我验证现在的判断，而不增加太多负担？ | 给可选择的实验，不自动创建 Todo |
| U23 | 当我想帮助别人、承担责任或抓住机会时，哪些时候需要检查边界？请给具体情境。 | 不把善意自动诊断为控制欲 |
| U24 | 如果一年后的我否定了今天的画像，哪些结论最值得优先复核？你会怎样修订它们？ | 模型服务未来的自我，不锁住身份 |

## B2. 二十四个新增专题问题（U25–U48）

> 它们来源于 **通用化后的提问模式与覆盖审计**，而不是某一个人的特殊故事。用户只需选最感兴趣的一题；AI 必须先核对自己到底有哪些资料。**“看见一个问题”不等于“本人赞同问题前提”。**

### 关系、吸引与互惠的细分（U25–U32）

| ID | 用户可以向 AI 问什么？ | 需要保留的区分 |
| --- | --- | --- |
| U25 | 我对某人的**珍视、需要、欣赏、认同、想要亲近、适合和愿意承担责任**，哪些能分开？能从哪些事件看到？ | 不把多个不同判断压缩成“喜欢” |
| U26 | 在我的真实关系中，友情、爱情、同行、合作和照顾各是什么关系？有没有不适合贴标签的情境？ | 类型未必互斥，也未必呈单一连续谱 |
| U27 | 当我被一个人吸引时，是对其品质的欣赏、精神共鸣、相处愿望、身体亲密愿望，还是想建立恋爱关系？哪些还不知道？ | 感受、行动意愿与关系承诺分开 |
| U28 | 我是否倾向于通过提供知识、资源或照顾来靠近别人？有哪些**不需要我提供帮助**也能成立的关系反例？ | 帮助不自动等于有目的的接近 |
| U29 | 当别人表达更亲密的愿望、而我暂时无法确定时，我的表达和行动是否兼顾诚实、自由与对方知情？ | 不预设谁应该回应或承诺 |
| U30 | 我面对关系误解时，有哪些真正帮助修复的行为？哪些可能只是让我自己暂时不焦虑？ | 需要双方材料才能评价修复效果 |
| U31 | 我是否容易接受被照顾、被喜欢而不必有用？哪些具体相处能支持或反驳这个理解？ | 被需要与被喜欢可以同时存在 |
| U32 | 当关系中存在经验、年龄、身份或权力差异，我怎样理解自己的影响力并尊重对方的主体性？ | 不推断第三方私人动机，不把差异自动视为不平等 |

### 基于“我问过什么”的自我发现（U33–U40）

| ID | 用户可以向 AI 问什么？ | 需要保留的区分 |
| --- | --- | --- |
| U33 | 如果你**确实能查看**我的历史问题，请按时间和主题整理我持续关注什么，并说明样本覆盖与遗漏。 | 有多少条记录不等于一生的全部兴趣 |
| U34 | 我最常向 AI 做哪类动作：求事实、求解释、质疑、比较、创造、求安慰、决策还是执行？请用真实问句举例。 | 问句功能不必只有一种，禁止伪精确比例 |
| U35 | 哪些看似无关的提问，可能反复体现同一种思考方法？哪些只是巧合或工作需要？ | 相似提问不等于唯一人格机制 |
| U36 | 我有哪些跨学科类比或方法迁移？哪些最后形成了可验证的实践，哪些只是有趣联想？ | 兴趣、原创性、科学效度、完成度分开 |
| U37 | 有没有我反复追问却从未真正得到满意回答的问题？缺的是事实、解释、情绪回应还是行动方案？ | 多次追问不等于强迫或人格问题 |
| U38 | 我向 AI 询问的主题，和我真正的日常生活之间可能有什么**样本偏差**？ | 沉默不等于缺失，聊天记录不代表整个人 |
| U39 | 我的提问中有哪些观点只是引用、试探、假设、反对或转述？你以前有没有误归属给我？ | 发问不等于认同；纠正说话者 |
| U40 | 如果让你从我的问题历史中选出三类我可能忽视但值得探索的生活领域，会是什么？为什么不是随机推荐？ | 有记录才谈覆盖，没记录就承认未知 |

### 兴趣、审美、创造与梦境（U41–U44）

| ID | 用户可以向 AI 问什么？ | 需要保留的区分 |
| --- | --- | --- |
| U41 | 我欣赏的学者、历史人物、虚构角色与作品之间有什么不同的吸引点？哪些是喜欢、认同、比较或向往？ | 不能从喜欢某角色推断与其人格相同 |
| U42 | 从我具体喜欢的音乐、语言、建筑、旅行或创作中，能发现哪些审美偏好？能否不把一切审美都解释成伦理？ | 审美与稳定人格、伦理之间不自动因果 |
| U43 | 我的兴趣和创造里，有哪些只为快乐，哪些希望影响现实，哪些还只是可能性？ | 不把喜好强迫变成成果和 Todo |
| U44 | 如果我主动提供梦境或似乎“应验”的巧合，你能区分**事前记录、事后回忆、命中、部分相似、未应验**，而不是直接断言预知或潜意识真相吗？ | 不用梦境推断他人意图、疾病或超自然能力 |

### 决策、边界与对 AI 的自我审查（U45–U48）

| ID | 用户可以向 AI 问什么？ | 需要保留的区分 |
| --- | --- | --- |
| U45 | 我面临的职业、金钱、学习与项目选择中，哪些资源是现金，哪些是时间、自由、能力训练或可逆性？哪些代价由我自己选择？ | 资源不是单一薪资或声望，建议不等于决定 |
| U46 | 我怎样区分“看见美好可能性”“有能力帮助”“愿意行动”与“已经承担责任”？哪些真实决定支持你的判断？ | 潜能不等于义务，善意不等于控制 |
| U47 | 如果你给我 MBTI、人格特质、年龄感等标签，哪些只是主观比喻、哪些能由行为支持，哪些需要正式测量？哪些结论你应该拒绝作出？ | 不用对话代替临床诊断或测量效度 |
| U48 | 请审查目前人物模型中**最有吸引力却最缺证据**的一条解释：来源是否真实、是否过度叙事、需要什么反例，是否该降权或撤回？ | 允许模型保持未知、退役或被本人否定 |

### 两个容易在通用关系题中被抹平的细节（按需追问）

- **共同成长**：当某个重要的人获得成长时，我为什么会有自己也成长的感受？是共同投入、价值共鸣、角色认同，还是其他原因？哪些场景不成立？（搭配 U25 / U26；不要推断对方也有同样体验。）
- **对真诚的吸引**：我是否特别被言行一致、坦诚或道德坚持吸引？请用我实际表达过的欣赏对象和反例判断，不要把审美好感直接升格为完整道德人格。（搭配 U25 / U27 / U41。）

它们是**动态追问示例**，不是新增必须回答的题目；目的在于保留原来宽泛“关系”分类下容易丢掉的不同机制。

## B3. 结合个人资料回答新增题的规则

- **有资料先检索**：U33–U40 只能基于确实能访问、已授权的历史问题或文件做纵向比较；无数据时说清“我只知道目前这段对话”。
- **有反例先诚实展示**：讨论关系和动机时，区分本人自述、可见行动、第三方明确评价、AI 假说；不可揣测第三方的真实内心。
- **重要又不确定的议题保持开放**：亲密、身份、健康、梦境、年龄感都属于自愿、可跳过的专题，不自动生成诊断或高置信人格标签。
- **少量问题创造深度**：针对一个 U 问题回答到有证据、有反例、有边界即可；无需顺序完成 U25–U48。
- **避免伪精确覆盖率**：历史问句频率、主题占比、心理年龄感或“理解程度”若无法审计来源及分母，不编百分比。
- **避免自证循环**：不能依据先前 AI 推断再证明先前 AI 推断成立；同一段聊天经多次归纳不算独立证据。

## C. 让 AI 回答得更可靠的四个通用追问

这些是**审查指令，不计入 U01–U24 主问题库**：

- “**来源呢？** 每项关键判断请指出你确实读到的材料、说话者、情境与时间。”
- “**反例呢？** 有哪段资料不支持你刚才那个说法？”
- “**别替我决定。** 哪些是你的建议，哪些才是我本人明确确认的目标？”
- “**现在改正。** 我刚才说的不是这个意思，请撤回基于错误归属产生的推断。”

## D. AI 回答规范

默认按以下顺序，依需要简化：

```text
简要回答：当前最有根据的判断（或承认不知道）
→ 依据：至少 1–3 条确实可见的来源、具体事件、时间与说话者
→ 限定：不适用的情境、证据缺口及竞争解释
→ 可反驳：什么未来观察能让这条判断降权或撤回
→ 用户修订：欢迎直接指出错在哪里，必要时更正记忆/文件
```

**不得**：
- 编造已读取的历史、第三方评价或心理测量分数；
- 将“我问 AI 自己是否有病”推断成用户有该病；
- 把外部作者/讲师的话写成用户本人已经掌握的能力；
- 通过自信语气代替证据，把所有用户缺点转义成优点；
- 在未获授权时把个人报告对外分享或写入公共项目。

如果没有个人材料，最好的回答可以是：“这件事我还不能可靠判断；目前只有你的这个提问。是否愿意讲一个最近的例子？”

## E. 如何和 Discover Me 形成闭环？

1. 用户选择 U 问题时，AI 先基于已授权材料回答。
2. 如果信息不足，AI 可以从 [Discover Me](discover-me.md) 选择**一个**最能区分竞争解释的追问。
3. 用户可以直接纠错；改变的是具体主张及其证据等级，不应擦除过去发生过的事件。
4. 用户可说“这里就够了”，不用把每段对话都升级为长期档案。

核心原则：**AI 提供可以质疑的镜子，不给用户一套不能反驳的身份判决。**
