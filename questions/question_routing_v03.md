# Question Routing Cards · v0.3（54 + 54）

> 这是一套**用于选题的人工维护标签**，而非科学验证的正交变量或自动诊断规则。所有字段均可修改；一题可涉及多个维度，此处的“首要维度”只是帮助 AI 找到下一题。公开文件只有方法，不含私人答案。

## 0. 选题通用门槛

1. **需要先知道用户想要什么**：即时事实回答、普通陪聊、主动探索与检验模型是不同任务。没有探索需求，不启动问卷。
2. **只问一个有理由的问题**：先复述用户的真实表述，识别未解决的事实、个人意义、情境、时间差、反例之一；能直接回应则不问。
3. **敏感度不是置信度**：低/中/自愿代表访谈负担与隐私边界，不代表这个问题有多重要。
4. **回答可得性**：若 AI 没有实际读取某项历史资料，不能从猜测生成回答，更不得称“已研究完整语料库”。
5. **退出不需理由**：允许“跳过、不分析、不保存、以后再说”。禁止围绕用户拒绝的主题换词追问。

## 2. AI 怎样判断下一问值不值得？

使用**定性**筛选而不假装获得经校准的信息增益数值：

| 问题 | 允许进入下一轮的条件 | 不该追问的情况 |
|---|---|---|
| **相关** | 与用户眼前问题和本人目标相关 | AI 只是为了填满维度 |
| **可区分** | 新回答能区分两种合理解释 | 得到的只是另一个形容词 |
| **可落地** | 能获得一个真实例子，或明确一个不可知 | 强迫空泛自评 |
| **安全** | 用户自愿、低负担、不索取第三方隐私 | 涉及拒绝的敏感主题 |
| **非重复** | 尚未从已有材料获得 | 反复让人重讲同一件事 |

当用户只是在聊天、没有新的证据差别、或当前状态不适合探索时，最好的下一问就是**不问**。

## 3. 把用户过去的答案写入自己的资料库

- 首先**检索现有资料**，为每条答案记录文件路径、事件时间与记录时间、说话者和证据类型。
- **只写足够支持的部分**：SELF_REPORTED / EVENT / OBSERVED / INFERRED / UNKNOWN 分开，并记录反例与竞争解释。
- **不要编造“用户曾经回答 D49”**：新题是今天设计的；旧材料可以构成一个 **RETROSPECTIVE_DERIVATION（回溯推导）**，不是用户刚刚亲口作答。
- 个人健康、家庭、亲密关系等材料放入本人自有私有空间，源自第三方的记录最小化；不保存原始秘密，也不推送到公开 Framework。
- 没有根据的题目以 **UNKNOWN + 下一条自愿补充问句** 收尾，不能用旧 AI 画像当作独立来源循环论证。
- 提供纠正和撤回渠道，不把个人新的自我反思自动变成待办任务。

## 4. 版本纪律

- 题目 D01–D54 / U01–U54 **ID 稳定**，修改文字不重排历史编号。
- 同一个题可能跨不同维度，首要分类仅用于检索；不要声称 12 维已实证正交。
- 不以“历史问题覆盖率”作为目标函数；历史 Q 条目同时包含科研、工具使用和执行命令，作为人物证据需要更谨慎的解释门槛。
