# 从不会提问，到拥有自己的 SecondMe 完整报告

> 这是一条**人可以走的路线**，不是后台已经部署的自动个人 Agent。本框架的提示词可复制到支持对话的 AI；保管材料和报告的方式由使用者自己选择。

## A. 0 分钟：先有一次轻松的交流

打开 [引导式探索提示词](../prompts/guided-exploration.md)，全部复制到 AI，开始对话。不必先做 20 类题库，也不必提供姓名、地址、医疗和第三方聊天。

例如可以说：“我不知道该从什么开始，你来问一个自然的问题。”“我最近越来越喜欢慢慢做早餐。”这就够了。AI 应当追问具体经历，而非立刻总结为“高尽责”。

## B. 初步探索：让问题随着你变化

几次对话后，AI 会尝试从你的真实材料中找出未探索的部分、相反的情境、发展变化和普通生活。你也可以直接使用 [下一步问题提示词](../prompts/next-questions.md)：

“我现在不知道继续问什么，请从已有材料里推荐三个最有信息价值、相互不同的问题。”

AI 不应机械问完十二维。你可以跳过、说不知道，或表示只想聊天。

## C. 获得第一个“可被纠正”的小结

一次有意义的对话后，你可以要求：

“请把你从这次对话里知道的事实、你推断的内容、反例和还不知道的东西分开写；别定义我一生。”

只有一次对话，就产出临时小结；不宣称完整人格结论。

## D. 建立私有的长期连续性

选一种自己接受的方式保存摘要：

- **无需 GitHub**：自己保存为本地 Markdown，下一次只粘贴愿意提供的相关部分；
- **GitHub 私人仓库**：从 [模板](https://github.com/CochraneK/Secondme-Framework/generate) 新建 Private 仓库，在 `my/` 放本人资料，`custom/` 放输出偏好。详细见 [入门](START_HERE.md)；
- **其他信任的私人知识库**：自愿选择自己能够控制权限的工具。

当前 Framework **不具备自动读取历史聊天、替用户长期存储或后台扫描** 的运行能力；即便 AI 服务自身可能有记忆功能，也不能默认它能够读取全部资料。

## E. 从短小小结逐渐走向独特的综合报告

当材料积累后，调用 [Full Output 提示词](../prompts/full-report.md)，要求可独立阅读的 Markdown 报告。将结果自行保存在私人 `my/reports/OUTPUT_FULL.md`。可以参考 [空白 Output 模板](../templates/OUTPUT_REPORT_TEMPLATE.md)，但标题与长短随这个人改变。

报告的“完整”应看重要主题、纵向变化、优缺点、反证和未知，而不是某个固定“完成率”。

## F. 每次有新材料：做增量而不是推倒重来

使用 [更新 Output 提示词](../prompts/update-output.md) 与旧报告一起进行比对。产出具体 `Delta`：支持、削弱、撤回、不变。只有材料足够时更新长期模型；普通经历也可以只保存。

## G. 愿意长期深入的人可以探索什么？

工作、身份、主体性、研究、创作、文化、书籍、音乐、梦境、普通快乐、旅行、关系中的差异、人生历史、反事实、未来不确定性……[20 类专题](../framework/personal_domains.md)是选择地图，[自适应探索](../framework/adaptive_discovery.md)决定何时提出一个好问题，[纵向修正](../framework/longitudinal_reasoning.md)帮助纠错，[八种判断镜头](../framework/judgment_lenses.md)在合适的时候澄清想要与责任。

不要求每个人都对这些方面进行分析；有意义的完全个人化结构往往从某个特别在意的主题长出来。

## H. 如果想让别的人也有类似能力，框架能保证什么？

**能提供：**第一问、探索路径、反例意识、覆盖提醒、证据层级、报告写法、后续更新规程和用户修正权。

**不能保证：**AI 一定有长期记忆、使用者已提供足够事实、每个人产生相同的身份结构、每段交谈都具心理学效度，或者无需维护即可自动生成 99 页报告。

## 给不知道说什么的人的五条可复制指令

> “我不知道该说什么，请从一件普通小事问起。”

> “这段话你可能理解错了，你再给一种不同解释。”

> “还有什么重要问题，是我自己不太会想到的？”

> “只用你真正看到的材料，给我一份充分的阶段 Output。”

> “这是我的旧报告和新经历，帮我做 Delta，而不是把我重新贴标签。”

不需要先成为研究者，才能开始认识自己。
