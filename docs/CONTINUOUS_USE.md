# 从第一次聊天，到一份属于自己的长期 SecondMe

> **v0.5 候选使用指南**。不需要先学 Git、安装 Agent 或提供多年聊天记录。你可以先用日常聊天工具体验；需要连续保存时，再选择私有存储。

## 选择适合自己的起点

| 你目前能做什么？ | 今天的唯一下一步 | 将来能得到什么 | 现在不能保证 |
| --- | --- | --- | --- |
| **只有 AI 聊天窗口** | 复制 [零代码主控提示词](../prompts/initialize-private-secondme.md)，从一个具体小事开始 | 阶段性洞察、可复制的事实卡和交接摘要 | 不能自动跨平台读旧对话或保存 Git |
| **有自己的 Private 仓库，但不懂代码** | 在自己仓库创建一个私人 Markdown 文件，粘贴 [Evidence Card](../templates/EVIDENCE_CARD_TEMPLATE.md) | 有来源的长期积累；下次可给 AI 相关文件 | 不能因为建了仓库就自动有长期记忆 |
| **已连接允许读/写的工具** | 告诉 AI：“用我授权的私人仓库执行 capture & delta，并在写后复核” | 更低摩擦的证据/模型维护与版本提交 | 工具不能访问的历史仍是 UNKNOWN |
| **已有大量历史笔记** | 用 [历史问题整理提示词](../prompts/build-question-atlas.md) 先生成可追溯目录 | 问题 Atlas、主题地图、报告检索入口 | 不保证全账号问题已被收集 |
| **已有充分的长期资料** | 用 [Full Output](../prompts/full-report.md) 与 [Visual Deck](../prompts/create-visual-deck.md) 分阶段生成 | 多维分析、个人说明书、可编辑 PPT（若工具支持） | 长文/图表不能替代真实证据 |

## 示例：第一周怎么开始（不设置每日打卡压力）

**第一次**：说一件愿意讲的普通小事。AI 先回应，再在你希望归档时生成最少量摘要。仅仅聊天也完全可以。

**第二次**：如果是新聊天，把上次的短交接摘要粘贴给 AI；让它明确说明能看到什么，不能看到什么。它可以追问一个反例，也可以只是继续聊天。

**第三次**：若你发现 AI 认错了说话者、误解了你的意思，直接更正。AI 应撤回错误推断并更新受影响的私人记录，而不是替旧故事辩护。

**以后**：材料自然变多后，生成完整 Output-only；缺少生活/身体/他人真实反馈的部分明确留白。需要外部展示时，另做可分享版本，而不是直接复制私人全文。

## 从完整人物报告生成更多东西

- **个人说明书**：把已证实/待验证的优势、环境适配、沟通方式、常见误解、边界和本人喜欢的提示方式翻译为便于阅读的版本；不替别人决定关系。
- **问题库**：记录真实历史问题、询问方式和新开放问题；用来源标签辨别原话和 AI 归纳。
- **阶段报告**：这段时间实际发生了什么，哪些解释有了改变？保留 NO_MODEL_CHANGE。
- **人物图鉴 / PPT**：单独决定受众，脱敏后从报告中挑选可核实的主张制作视觉作品；有工具才能导出真正可编辑文件。

## 推荐的轻量私人目录（按需，不必一次创建）

    my/
      evidence/                 # 一条条可追溯事实
      people/ENTITY_REGISTER.md # 多人说话者归属
      models/CLAIMS.md          # 可撤回的长期解释
      questions/QUESTION_ATLAS.md
      reports/OUTPUT_FULL.md
      reports/CHANGELOG.md

所有示例路径都在**你自己的私人存储**里。实际保管地址、是否使用 GitHub、哪些领域不记录，由你决定。

## 不应发生的五件事

- 还没有长期材料，就生成装满漂亮词语的“权威人格报告”。
- 把“我猜测你在意什么”当成用户说过的原话。
- 把一名聊天对象与另一名因昵称相似而合并，进而污染所有画像。
- 把每次普通聊天强迫变成信息采集、心理诊断或新的待办事项。
- 把私人完整报告直接上传公共平台，或声称 Git 已提交而没有检查。

## 对已有私有 SecondMe 的升级方式

本次 v0.5 方案属于**方法文件与模板**，不是改变任何现存人物记录。已有私人副本如启用官方 Updater，可在官方正式发布新 manifest 后收到候选更新 PR；依赖自己审阅和合并。新方法的存在不会自动重新解释某个人、安装后台或把历史补齐。

**一切以当前确实可访问的存储和工具权限为准。** 参见 [更新器说明](UPDATES.md) 和 [隐私规则](../PRIVACY.md)。

## 最后一个问题：什么时候才算成功？

不是拥有多少文件、多少问题、多少页 PPT，而是：
1. 在新会话里能找到真正相关的旧事实，不用重复讲全部人生；
2. 能识别“我没说过这个”“这是别人的话”，及时撤回；
3. 有实际帮助自己的判断、作品或生活选择；
4. 能让本人轻易说“不对”“不想记录”“这一版不适合分享”；
5. 不因为建模而失去普通生活的时间。

> **同样的方法可以帮助很多人，但不能要求每个人活成同一份报告。**
