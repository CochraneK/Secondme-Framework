# Need–Want–Value–Fit–Believe–Ought–Can–Choose｜八种判断镜头

> v0.4 · 非正式量表、非经验证的八因素人格结构、也不是必须采用的唯一理论。思想与现实生活中的概念区分可因人而异。

## 为什么有用

人的决策经常混合：“这很有价值”“我需要它”“我能做到”“所以我必须做”。它们并不逻辑等价。

| 镜头 | 核心问题 | 避免的误判 |
| --- | --- | --- |
| Need 需要 | 哪种缺口、功能或关系需要被满足？ | 没有需求 ≠ 不珍视 |
| Want 想要 | 我主观上有多渴望它？ | 珍视 ≠ 必须拥有 |
| Value 珍视 | 我认为它本身有什么价值？ | 道德认同 ≠ 亲自承担 |
| Fit 符合 | 按明确的标准与现实条件，它是否适配？ | 匹配 ≠ 想要 |
| Believe 相信 | 我相信哪条事实命题？证据怎样？ | 希望它真 ≠ 相信它真 |
| Ought 应当 | 按被我认可的规范，谁有什么责任？ | 我能做 ≠ 我必须做 |
| Can 能够 | 资源、技能、时间、机会允许吗？ | 有能力 ≠ 有义务 |
| Choose 选择 | 我实际决定做什么、保留什么、不做什么？ | 想法 ≠ 决定 |

## 方法边界

- 八项不是互相独立的心理测量因子，`Choose` 是决定/行为而非人格 trait，`Believe` 面向命题，`Value` 往往面向目标或对象。
- 不强制所有八项都有数据，也不能加权出“正确选择”。没有正式测量不产生人格分数。
- 遇到关系、职业、创作、伦理与消费可选择其中两三项帮助厘清；有的生活体验不需要此框架。
- 任何关于“应当”的建议都要检查其来源：本人认同的责任、别人施加的期待、法律义务、还是 AI 的规范想象？
- 允许 `unknown`、`not_applicable`、`conflicting`，允许新证据推翻旧选择理由。

## 完全虚构例子

一位童话岛上的修桥学徒收到邀请去主持祭典。她认为社区的活动值得保存（Value），也有组织能力（Can），却并不希望亲自主持（Want 低），而且这不属于其承诺过的责任（Ought 尚无）。她最后选择提供少量技术协助而非负责到底（Choose）。

该例是独立虚构方法说明；不得引用成任何真实用户的个人经历。

## 适用方式

当用户说“我不知道为什么明明觉得很重要却做不了/不愿做”，先问一个区分问题：“你是在说它值得被做，还是你决定由自己来做？” 其他时候不必主动搬出八维表格。

> 好的模型不把所有能做的事都变成个人义务。
