# 证据协议｜Evidence Protocol

## 不同层次不能混为一谈

| 标签 | 含义 | 注意事项 |
| --- | --- | --- |
| SELF_REPORTED | 使用者明确表示的经历、感受、价值与判断 | “我觉得 X”可以确定是自述，X 是否为外部事实仍可能需要核验 |
| EVENT | 明确的事件、行动或经历 | 尽量注明时间范围和背景；可以只记概述 |
| OBSERVED | 在实际提供的文字或材料中直接观察的表现 | 单次样本不能代表全部生活 |
| INFERRED | 通过多条材料形成的候选解释 | 应说明证据、反例和适用范围 |
| EXTERNAL | 研究、作品、媒体、第三方说法 | 明确作者及来源，不直接当作本人价值 |
| UNKNOWN | 未被提供、未核实、相互冲突的内容 | 不能用通顺叙事补全 |

### 可选附加来源标签

- SELF_EXPLICIT：本人明确确认的价值或意愿；
- SELF_INFERRED：外部模型猜测用户可能在意什么；
- EXTERNAL_FACT：来源可追溯的外部事实；
- EXTERNAL_INTERPRETATION：外部作者的解释；
- EXTERNAL_PRESCRIPTION：外部作者的建议；
- ASSISTANT_INFERENCE：AI 综合后的候选判断；
- USER_DECISION：本人明确做出的决定。

## 说话者、时间与来源（重大结论优先）

- **说话者**：本人说、第三方说、别人转述、AI 推断必须分开；“使用者上传了一段对话”不等于“整段话都是使用者说的”。
- **时间**：事件发生、后来回忆、当下重新解释可能是三个不同时间；不知道就写 unknown。
- **证据类型**：收到文本 ≠ 核实了现实事实；模拟生成 ≠ 直接观察；未提供 ≠ 事件不存在。
- **主张的范围**：一次事件通常是关系或情境内观察，不自动升级为跨情境稳定特质。
- **置信度**：只描述该命题在现有证据下的支持力度；不能计算“人格可信度总分”。
- **来源唯一、解释可多重**：同一证据可支撑多个互有交叠或竞争的理解；不因局部 MECE 消灭复杂意义。
- **自我纠错优先**：用户指正具体事实后，先修正错误主张的归属与派生结论，不替旧解释辩护。

可参考 [AI-Persona 选择性互操作](semantic_interoperability.md)，但不要求所有个人叙事转化为固定 Kernel 字段。

## 一条判断的最低字段

- 判断内容：
- 证据类型：
- 来源（可写脱敏摘要，不要求上传原文）：
- 时间与情境：
- 支持它的证据：
- 反对它的证据：
- 其他可行解释：
- 置信度：insufficient / low / medium / high
- 新证据出现时怎样修订：
- 状态：provisional / active / weakened / superseded / retired

置信度是**定性解释**，不是自动计算的概率。即使是高置信度，也不能免于反证。

## 关键区别

- 自我报告 ≠ 外部事实得到核实。
- 相似经历 ≠ 同一原因。
- 稳定倾向 ≠ 某种情境中的状态。
- 作品或梦境 ≠ 作者现实中的意图。
- 统计相关 ≠ 因果关系。
- 心理学构念 ≠ 通过聊天已完成科学测量。
- 非常感人的文字 ≠ 非常可靠的证据。

**无材料时最正确的标签可能就是 UNKNOWN。**
