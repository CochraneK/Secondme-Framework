# Continuous SecondMe｜从一次聊天到长期私人认知系统

> v0.5 候选方法。**公开的是流程，不是任何人的人物资料。** 当前仓库只提供可复制 Markdown / prompts；没有后台常驻记忆、跨账号自动检索、自动分析或自动 Git 写入服务。

## 想实现的体验

每个人可以从一次普通聊天开始，逐渐拥有：可追溯的经历、可撤回的解释、自己的问题地图、随时间修订的人物模型、充分的 Output-only 报告，以及经审核的分享稿。**结果因人而异，证据的丰富性不能由提示词凭空产生。**

## 七步闭环（任何一步都可以停止）

| 阶段 | 何时触发 | 最小成果 | 不应发生 |
| --- | --- | --- | --- |
| 0. CHAT | 用户只是聊天 | 自然回应；必要时给一次自愿记录提议 | 强制心理测评或把每句闲聊升级项目 |
| 1. CAPTURE | 本人要求保存，或授权长期记录 | 一条含来源/说话者/时间的私人事实卡 | 把 AI 解读写成用户原话 |
| 2. DISTILL | 累积了同主题多条线索 | 可区分事实、候选解释、反例的小结 | 单次表现直接升成终身性格 |
| 3. MODEL | 需要了解持续模式/情境差异 | 带 claim ID 的可修正工作假设 | 为了统一叙事抹平矛盾 |
| 4. ASK | 用户想知道自己过去问过什么或还缺什么 | 历史问题地图或自愿新问题 | 将假设性归纳冒充历史原句 |
| 5. REPORT | 用户需要全面、专题或阶段总结 | 阅读友好的 Output-only Markdown | 假装看过未授权的旧聊天 |
| 6. SHARE / REVISE | 请求视觉展示、对外分享、或补充新证据 | PPT 方案/访客版、Delta 与版本说明 | 私有全文直接公开；每次重写历史 |

## 事实唯一源，输出是多种投影

建议在个人选择的**私人存储**中保留以下少数路径（按需创建，永不要求一次建满）：

- **my/evidence/**：可追溯的事实卡（可不上传高度敏感原始材料）。
- **my/people/ENTITY_REGISTER.md**：人物与说话者辨别的本地登记；可使用本地匿名标识。
- **my/models/CLAIMS.md**：结论 ID、支持/反证/适用情境、状态与原始证据链接。
- **my/questions/QUESTION_ATLAS.md**：真实问句与归纳候选分开。
- **my/reports/OUTPUT_FULL.md**：完整人物报告的阅读版；不替代事实层。
- **my/reports/CHANGELOG.md**：每次重要解释变更的前后对照与撤回原因。

不用 GitHub 也能将它们保存在自己选择的本地或受信任空间。**Canonical 的意思是“事实只有一个核查入口”，不是“一个人只有一种解释”。**

## 一次新材料的最小处理顺序

1. 问：这次使用者是想聊天、分析、保存，还是更新旧结论？先响应实际请求。
2. 核实可见的来源范围、说话者和事件时间；不知道就保持 UNKNOWN。
3. 将“本人明确说了什么 / 可观察行动 / 第三方转述 / AI 候选解释”分开。
4. 找可能关联的旧证据与模型（**只有实际连接并有权限的资料才可检索**）。
5. 提出最多一条值得新增或修订的主要洞察；寻找反例。
6. 新证据不一定修改模型。允许 NO_MODEL_CHANGE、PARAMETER_UPDATE、MODEL_REVISION、RETRACTION。
7. 如获授权且工具能写入：先检查目的地是否私人 → 最小化保存 → 重新读取验证。没工具就提供可复制内容和目标路径，不得声称已提交。
8. 只告诉用户最相关的结果与**唯一下一步**；不把每次交流改成考核流程。

## 逐步成熟，不设固定资料数量

- **轻量**：一次聊天和一个可纠正的发现（可在五分钟结束）。
- **持续**：若干经历、少量相反情境、时间线，随本人意愿修正。
- **深入**：多来源核对、个人词典、开放问题、长篇报告及阶段 Delta。
- **展示**：本人明确同意后，从经过裁剪的报告另写对外版和视觉版。

长期价值来自**时间 × 材料 × 纠错 × 真实生活**，不来自统一 12 章、固定人格总分或越来越多的追问。个人化叙事仍受 [person-specific modeling](person_specific_modeling.md) 保护。

## 能力边界与失败状态

- 无权限/无可见材料：标为 NOT_ACCESSIBLE；只分析当前内容。
- 人物归属不明：先按 [Entity & Attribution Gate](entity_attribution_and_corrections.md) 冻结有关推断。
- 来源不足：只保存事件，不声称“已经形成稳定模式”。
- 外部模型或理论来源：只能作为竞争解释，不自动变成本人的信仰。
- 用户说“不准确/别记录”：更正、停止升级或按存储服务的实际删除能力提供操作说明；不虚称撤销云端历史。
- 每次输出之后：执行源头、事实、反证、隐私与写入结果核验。
