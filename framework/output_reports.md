# Output Reports｜长期人物报告而不是固定画像卡

> v0.4 · Output 指可复制、可交接、可自行保存与更新的分析成果。没有隐藏数据库或自动跨聊天记忆功能。

## 目标与类型

- **完整 Output-only**：尽可能充分解释一个人的特质、价值、行为机制、关系、时间变化、工作/学习、兴趣、优势、局限、矛盾和未知，但章节随这个人真实材料**自由增减**。保留证据链接而不是复制全部 raw input 或推理过程。
- **阶段 Delta**：这段时间新发生什么？旧结论有哪些不再成立？不重复整份人物报告。
- **专题深描**：集中处理一个真正重要的主题，允许诗性语言、图谱、表格、长文与多重解释。
- **访客 / 对外版本**：经过单独授权、充分隐私审核后的**选择性重写**，不能把私有完整报告自动公开。
- **Machine projection（可选）**：仅在需要跨工具协作时转换为有来源的字段；不替代叙事文本。

## Report 的结构不是相同内容

最低必要的是报告元信息（日期、来源范围、未纳入内容、状态、更新方式）和**对核心判断的事实/解释/未知区分**。章节数量、章节名称和叙事长度由使用者目标和证据密度决定，切忌为了“全”而补造经历或固定心理标签。

建议但不强制的模块池：

| 可选模块 | 典型内容 |
| --- | --- |
| 当前是谁 | 自我理解、想保留和不认同的外部标签 |
| 优势、局限、双刃剑 | 每个优点适用的条件、什么时候会成为代价 |
| 学习与认知 | 思维机制、审美与表达、真实能力证据 |
| 价值与动机 | 珍视、需要、想要、相信、应该、能够、选择 |
| 职业与创造 | 已有实践、决定、环境适配和未选择的路径 |
| 人际与边界 | 自己的互动方式，不替第三方推断内心 |
| 生活与乐趣 | 普通日常、休息、兴趣、文化、身体节奏 |
| 时间与转折 | 事件当时/后来解释、改变和未改变 |
| 独有的个人概念 | 无法被标准分类涵盖的词汇、意义与张力 |
| 证据与反例 | 强判断与弱判断分开，哪些来自自述、哪些是推断 |
| 尚未知/不想记录 | 留空合法，不视为缺陷 |
| 模型修订记录 | 错过什么、改了什么、未来什么能推翻新版本 |

## 综合报告的产出流程

```text
明确受众和来源范围
   ↓ 确定能访问的私人材料与日期
证据索引（先核查身份、时间、引用；明确缺失）
   ↓
人物独有的主题发现与模块选择
   ↓
每个重要结论的证据、反例、情境和时间限定
   ↓
自由的长篇 narrative + 有用的表格/图
   ↓
总体优点、局限、冲突、开放问题
   ↓
用户校对（事实更正优先于 AI 美化）
   ↓
保存 Output-only Markdown + 版本/日期
   ↓
下次先产阶段 Delta，按相关章节更新完整版
```

## 可计算≠必须评分

可以用透明统计、数据覆盖度、时间线或关系矩阵检查**数据缺失与比较问题**。缺乏规范测量或足够样本时，拒绝虚假的 OCEAN 分数、诊断、精确恋爱成功概率或全局人格排名。文字长不等于可信：每个强结论应经得起“哪条来源支持、什么会推翻”的追问。

## 完整性的正确理解

完整 ≠ 12 维和 20 专题全部填满。完整更接近：
1. 没把使用者认为重要的主题遗忘；
2. 保留纵向的变化、反例和独有语言；
3. 体现不同领域的强弱、环境和人际差异；
4. 不把未经验证的空白填成事实；
5. 读者可以发现哪里来自证据、哪里只是 AI 假说；
6. 下次有增量更新办法而非每次重写一切。

在记录前先问用户是否需要第三方视角、健康或其他敏感主题；不要求提交原始私信、第三方身份和位置。

## 从对话到文件

使用 [Output 提示词](../prompts/full-report.md) 可在任何对话工具中生成可复制的 Markdown；没有连接文件/仓库写入工具时，只能把报告交给使用者手动保存，**不能声称已同步 Git**。建议由使用者在 Private 仓库创建 `my/reports/OUTPUT_FULL.md` 并维护 `my/reports/CHANGELOG.md`，这些是私人路径，不进入公开仓库。

以 [报告模板](../templates/OUTPUT_REPORT_TEMPLATE.md) 开始，但可以删改章节；不应为版式牺牲个性。

> 好的 Output 报告应帮助使用者认出自己，同时也容易指出“这里你想错了”。
