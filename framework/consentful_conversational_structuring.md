# Consentful Conversational Structuring｜可选择的对话式澄清与证据结构化

> v0.5.1 候选方法。来自对一般交互设计和外部 HopeBot 研究的独立方法分析，不使用或复刻临床问卷。**仅当本人明确希望探索或保存时启用；正常聊天可以不进入任何采集流程。**

## 一条小而完整的对话链

```text
用户自然叙述
    ↓ 先回应当下的需要，不强行采集
确实需要辨别的歧义？——否 → 只保存原话/不保存（依本人意愿）
    ↓ 是
一条中性澄清（可跳过、不知道、不愿说）
    ↓
候选结构化结果（不冒充已证实的人格）
    ↓
归属/时间/证据类型/隐私/缺失核查
    ↓ 本人愿意保存 + 有真正写入能力？
私人记录 → 后续反证与 Delta；否则可复制 Markdown
```

## 澄清门槛：什么时候值得追问？

只在回答**会改变解释、来源正确性或本人希望得到的结果**时追问，避免重复访谈。

| 需要区分 | 中性提问例子 | 允许的结果 |
| --- | --- | --- |
| 说话者 / 引用者 | “这句话是你说的，还是你转发的别人原话？” | 本人 / 第三方 / UNKNOWN |
| 事件发生时间 vs 回忆时间 | “这是今天发生的，还是今天回忆起以前的事？” | 一个时间 / 多个时间 / UNKNOWN |
| 一次感受 vs 稳定倾向 | “你说的是今天的状态，还是你也记得其他类似情境？” | 单次事件 / 多次事件 / UNKNOWN |
| 实际行为 vs 想法 / 意图 | “这次是已经做了，还是你在考虑一种可能？” | 已行动 / 计划 / 未知 |
| 用户话语 vs AI 推断 | “这里我理解为一种候选解释，对你来说准确吗？” | 本人确认 / 不准确 / 不想讨论 |

**注意：**问法应避免向用户暗示“你其实有创伤吧”“你是不是这种人格”。用户的“不知道”“没发生过”“拒绝回答”和“没有记录”须分别保留，不能都映射为零分或无症状。

## 分开的数据平面

- **Personal evidence（私人）**：仅本人授权的原话或最小摘要；含 speaker、subject、source_pointer、event_time 和隐私限制。
- **External knowledge（外部）**：理论、论文、社会资讯等按版权和来源引用，只支持解释可用性，不用来捏造个人历史。
- **Claims（私人候选解释）**：模型生成的假说与对立解释、反例、适用条件，引用到可追溯的 evidence。
- **Presentation（经审核的输出）**：报告、个人说明书或 PPT；不是新的独立事实源，也不能反过来加强模型置信度。

若有独立的标准化量表，题项内容、适用范围与数值规则应**外部固定并许可使用**；模型只负责在用户同意后帮助澄清，确定性规则负责运算。**本框架默认不启动任何临床量表或治疗流程。**

## 最小验证检查

1. **Attribution**：speaker / subject / quoted speaker 是否对应同一条可核实来源？不确定即冻结相关人格推断。
2. **Missingness**：跳过、不知道、不适用、缺记录、真正否定分别保存，禁止一律写成 `false` / 0。
3. **Temporal**：事件、记录、解释时间是否被混淆？
4. **Consent**：本人是否希望保存？是否真的有工具可写入指定的私人存储？
5. **Revisions**：一条旧推断被撤回时，能否找到相关的报告段落、卡片、题库和演示稿？
6. **Burden**：采集带来的时间与情绪负担是否高于实际帮助？没有收益就不要问。

## 一份完全虚构的极简示范

虚构人物“森禾”说：“昨天我看到蓝色风筝，突然想重新学画画。”

助手可以先正常聊这件事；如果森禾要求保存，就记为“一次想法与感受的自述”，不能写成“已报名绘画课程”或“具有稳定艺术天赋”。只有当森禾明确说已经参加课程，才新增行动记录。若不是必须，完全不需要追问“童年是否缺乏艺术表达”。

## 质量目标，不造分数

可测试：误归属率、引用证据是否存在、修订传播完成率、非必要澄清次数、完成时间、用户是否有权拒绝、真实输出是否能被本人更正。需要完整测试方案而不是宣称“更有同理心”就足够。

外部研究背景见 [HopeBot 独立评述](../docs/research/HOPEBOT_RESEARCH_NOTE_2026.md)，现有来源和纠错方法见 [Evidence Protocol](evidence_protocol.md)、[Entity & Attribution Gate](entity_attribution_and_corrections.md)。
