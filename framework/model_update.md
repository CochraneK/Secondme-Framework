# 模型持续更新｜Model Update

个人模型的价值不在于永远正确，而在于能被生活修正。

## 重要补充：允许不更新

`NO_MODEL_CHANGE` 也是正确结局：一段经历很重要，但只够存为事件或开放问题。新证据可能需要调整状态、关系或环境解释，而不需要修改稳定人格。详见 [纵向推理方法](longitudinal_reasoning.md)。

## 三类更新

1. **权重调整**：相同解释仍可能成立，但证据支持变强或变弱。
2. **解释修改**：出现更能解释事实的假说。
3. **分类修正**：旧维度不够合适，需要拆分、合并或增加情境限制。

## 面对矛盾

不要把不符合模型的经历自动删掉。先问：

- 时间或发展阶段是否不同？
- 情境、关系对象或角色是否不同？
- 暂时情绪是否被误当成长期人格？
- 不同材料是否可信度不同？
- 是否可能存在同时成立的两种行为模式？
- 现有分类是否过于粗糙？

## 可使用的状态

- provisional：暂定
- active：目前仍适用
- weakened：被新证据削弱
- superseded：被新解释替代
- retired：停止使用

## 变更记录模板

| 字段 | 内容 |
| --- | --- |
| 日期 | 发生修订的时间 |
| 原判断 | 先前怎么理解 |
| 新证据 | 新出现了什么 |
| 反例或竞争解释 | 有什么不符合 |
| 修订类型 | 权重／解释／分类 |
| 当前判断 | 仍保留哪些不确定性 |
| 下一步检验 | 什么现实观察可能再次修订 |

## 主体性保护

过去的模型**不能因为要保持“人格一致”而拒绝本人新的选择**。一个人可以改变兴趣、生活方式、价值甚至身份叙事，不必为了让 AI 描述方便而维持旧形象。

**不是要求现实符合模型，而是让模型学习现实。**
