# 方法选择器｜Method Router

## 原则

SecondMe 不要求先决定用户是某种“人格类型”，再从那里推出所有结论。

**先有真实问题，再选择必要方法。**

## 先让不会提问的人能开口

与其要求使用者自己挑理论，可以先使用 [自适应探索](adaptive_discovery.md)：从生活中的一件普通事情开始，每次一个问题。等材料足够再选择 1–3 个理论镜头；如果用户只想聊天，也可以不启动分析。

输出的内容按 [Person-specific Modeling](person_specific_modeling.md) 自由组织。两个人可以使用同一证据协议而形成完全不同的 Output 目录。

## 五个选择条件

1. 问题类型：想理解、解释、比较、决策，还是检验已有假说？
2. 分析单位：个人、双人互动、集体，还是社会环境？
3. 时间尺度：当下、一件事、一个阶段、跨多年？
4. 证据形式：自述、行动记录、他人反馈、文本、测量数据？
5. 什么新的真实证据能改变结论？

## 可选方法类别

- 人格与差异：大五、HEXACO（如需正式测量，应使用合格工具和规范解释）。
- 认知与学习：认知风格、元认知、信息加工。
- 动机与价值：自我决定理论、期待—价值。
- 情绪与情境：情绪调节、情境反应。
- 关系与沟通：互动循环、依恋与边界。
- 身份与时间：叙事身份、自我差异、可能自我。
- 行动与决策：成本—收益、趋近—回避、人—环境适配。
- 发展与社会：生态系统与人生历程。

这些是**参考理论池，不是已运行的自动模型**。

## 一次分析的流程

1. 保留原始问题；不要先套学术名词。
2. 确定已知事实与缺失信息。
3. 选择最多 1–3 个有不同预测的方法。
4. 对每种解释明确指出何种反例会使其变弱。
5. 确实没有合适理论时保留「未知」，不必发明新标签。

## 完全虚构的方法示例

某童话城里的居民「云豆」说自己“不喜欢学习新技能”；但在造纸节上，他每年都会学新的折纸技法。

候选解释包括：
- 他喜欢有真实成果、社群支持的学习情境；
- 他只是不喜欢某些被安排的学习方式；
- 也可能只是一年一度的娱乐，无法推测一般学习态度。

应继续观察，而不立即判定“学习动机低”。

> 以上是虚构教学场景，**不得作为任何使用者的个人记忆或推断依据**。

**理论是候选解释器，不是法官。**
