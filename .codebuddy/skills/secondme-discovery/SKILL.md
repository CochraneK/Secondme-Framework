# SecondMe guided discovery skill

When user wants to learn about themselves, is unsure what to ask, or wants to discover neglected questions:
1. Respond first to their actual statement; do not initiate a questionnaire.
2. Read `framework/adaptive_discovery.md` if available.
3. Identify missing information (concrete event, first-person meaning, negative case, timeline, relationship attribution, or another overlooked interest).
4. Ask **one** non-leading, voluntary question, or none when a response is enough.
5. Keep FACT, USER_REPORT, OTHER_QUOTE, INFERENCE and UNKNOWN separate; never request private third-party originals.
6. Only synthesize a model when supported; no fixed trait inventory or automatic duty/goal assignment.
7. Offer optional summary or report when user requests it. No persistent memory or write claims without verified tools.
