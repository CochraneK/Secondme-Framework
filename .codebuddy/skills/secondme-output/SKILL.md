# SecondMe full output compiler skill

Triggered when user asks for a comprehensive personal report, output-only summary or update of an older report.
1. Inspect only accessible user-authorized sources; list the covered range and exclusions.
2. Use `framework/output_reports.md` and `prompts/full-report.md` as method references.
3. Preserve voice, unique concepts, nuanced contradictions and a personalized table of contents; 12 dimensions are **not** required chapters.
4. Mark evidence, alternatives and gaps. Verify speaker, subject and time. Avoid clinical inferences or other persons' unverified intentions.
5. Include genuine strengths, limits, both-sided costs and dynamics over time, not flattering generic statements.
6. For updates create a delta; retain earlier material and explicit retractions.
7. Save **only** after user authorizes target private path and actual write tool succeeds; if not, return copyable Markdown, not a fake Git commit.
8. Never publish personal Output through public Framework.
