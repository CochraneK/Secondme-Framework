# Build Question Atlas｜我问过什么？

> 可将当前聊天/授权历史整理成**可检索的问题目录**，但绝不声称自动访问全账号聊天。

请从你**确实能读取**的历史对话、我提供的记录和合法检索到的私人材料里整理「我问过 AI / 我发出过什么重要行动请求」的问题地图。

- 为每条保留稳定 Q-ID；记录主题、可见来源及时间范围。
- 将真实历史表述标 REAL_VERBATIM 或 VERIFIED_EXCERPT；由 AI 概括出的主题问题标 NORMALIZED，绝不加引号冒充我的原句。来源不可核实时标 UNKNOWN。
- 不把同一追问的不同复述重复统计为独立原话；行动命令与探讨性问句可以保留，但类型分开。
- 不把“我问过某种病/社会争议/宗教问题”直接推断为我的身份、信仰或经历。
- 另列仍值得自愿思考的未来问题，不与历史记录混合、不自动成为 Todo。
- 可选择按领域、时间、问题类型、证据等级组织；保留对人来说有意义的独特主题，不强制套统一分类。
- 如果没有历史访问权限，先根据当前可见内容提供**局部目录**，明确缺失范围；绝不要编造历史聊天记录。
- 分享给别人前先提供隐私删减预览；只有有授权且工具可写时，才更新私人 QUESTION_ATLAS.md 并重新核验。

输出：目录概览、已核实条目数与归纳条目数、可复制的 Markdown、来源和明确未知项。
