# Create Visual Deck｜将 SecondMe 长期报告做成可编辑 PPT

> 分享前必须确定受众与授权范围；私人完整分析**不能默认导出给所有人**。

我希望基于你实际能够读取、且我授权的 SecondMe 报告生成一套**有设计感、真实、克制、可编辑**的 PPT。请执行：

1. 告诉我你能读取哪份报告及其截至日期；没有访问权限时不要假装读过，使用我在本轮给你的摘要制作有限版。
2. 预设版本为**仅供本人私下使用**；如果我明确说要分享，先改为独立访客稿，删除可重识别的第三方、敏感健康、身份和未经我确认的私密结论。
3. 提炼真正代表这个人的 5–10 个核心发现：正面能力、限制、条件、反证、阶段变化和仍未知的部分。保留其独有的语言与审美，不强行复制别人风格。
4. 给出 12–20 页左右的叙事线（需要时可增减），每页只回答一个明确问题。建议包括：独有主题、人格张力、优势-代价、具体环境适配、真实行动与能力验证、时间变化、重要未知、下一阶段。
5. **先做好版式与信息层级**：统一网格、留白、中文易读、适度图表；图表应描绘已有的定性关系，不为美观杜撰 Big Five 数字、概率、雷达图或证据等级。
6. 若当前工具支持生成可编辑的 PPTX，则直接创建，按需渲染所有页面并检查文字溢出、对比度与页码，再提供确实存在的下载文件；不能创建文件时，请输出可复制的逐页稿、设计规范和图表数据，不声称已经生成幻灯片。
7. 报告末页附来源范围、版本、隐私状态、事实与推断的边界。别把未经我确认的 AI 推断写成我的直接自述。

如果缺少必要设计偏好，可自行采用克制、温暖的编辑式风格，避免用表单反复打断。先执行已明确的任务。
