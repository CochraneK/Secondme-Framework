# Update Output｜把一次新发现更新进长期报告

> 用于用户再次带来材料时，不依赖隐含的跨会话记忆。

---

这里是我愿意提供的旧 Output 报告和新材料。请严格以可见内容为准，帮助我更新长期 SecondMe：

1. 首先指出此次新增了什么**直接事实、对原事实的更正、观点、外部反馈**；逐条确认说话者和时间，不要把其中的第三方心理状态推断成事实。
2. 做一个**Delta**：哪些旧命题得到支持、被削弱、被推翻，哪些只是在不同情境成立？允许 `no_model_change`。
3. 对需要改写的具体段落给出新文本，保留原来的情境、反例与不确定性；不要因为旧报告写得优美就拒绝纠错。
4. 不需要每次重写全文；如我明确要求“更新全量 Output”，提供完整更新版 Markdown，并更新版本、素材截至日期、变更历史。
5. 不把新发现自动升级成我已决定的职业/关系/Todo。
6. 原始私密材料与第三方身份不进入公开仓库；如需对外分享，请另做最小化、独立重写。

请先展示最重要的修订，再根据我要求输出完整报告或章节补丁。没有真实的读写工具就不要声称已经写入私人 Git。
